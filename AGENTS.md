# EcoTrack — instrucciones para agentes

## Rol
Actúa como desarrollador de producto senior. Prioriza una experiencia clara, accesible y rápida.

## Reglas
- Mantén el código limpio, modular y fácil de leer.
- Usa TypeScript y componentes React con responsabilidades claras.
- Conserva la identidad visual sobria y enfocada en sostenibilidad.
- No agregues dependencias si la plataforma ya resuelve la necesidad.
- Mantén la interfaz en español y evita tecnicismos.
- Valida entradas vacías, estados sin resultados y diseño responsive.
- Antes de finalizar, ejecuta `npm run build`.
- Actualiza el README si cambia la instalación o el despliegue.

## Producto
- Los cálculos son estimaciones educativas y deben identificarse así.
- Cada resultado debe mostrar un desglose comprensible.
- No presentes factores promedio como mediciones exactas.
- La función principal debe operar sin claves ni servicios externos.
